# 拼豆工作室 · Perler Studio

一个在浏览器里画拼豆图纸的小工具：在标准拼豆板上逐颗放豆、把照片转成图纸、顺手算清每种颜色要用多少颗。

纯前端、零后端，所有数据只保存在本机浏览器里。

## 功能

- **拼豆画布**：16 / 24 / 29 / 32 / 48 / 64 六种标准板尺寸，缩放到 220%，可切换网格与水平对称。
- **六种工具**：画笔、橡皮、油漆桶填充、直线、矩形框、吸管取色；拖动时有 Bresenham 补点，不会因为鼠标太快漏豆。
- **撤销 / 重做**：最多 60 步，覆盖每一笔、清空、换板、导入和套用模板。
- **39 色豆卡**：按基础 / 暖调 / 冷调 / 大地 / 特别分组，显示色号与 HEX。
- **图片转图纸**：拖入图片，实时预览转豆效果；可选抖动（Floyd–Steinberg）、去白底、cover / contain 裁切。颜色匹配在 CIE Lab 空间做最近邻，比直接比 RGB 更接近肉眼判断。
- **四种起手图案**：一颗心、小星星、彩虹云、蘑菇仔，一键套用。
- **珠子清单**：统计总颗数、用色数、铺满率，按颜色列出用量条；悬停某一行会在画布上高亮对应豆子。
- **导出**：
  - PNG —— 透明背景，2× 分辨率（单颗 24px），适合直接发给别人或当素材。
  - CSV —— 带 BOM 的拼豆清单，Excel / Numbers 打开不乱码。
- **打印图纸**：把画布排成 A4 图纸，每格印色号数字、顶部左侧标行列号、底部列色号对照表，黑白打印也能照着拼。29 及以下一张 A4 放下；32 / 48 / 64 会自动分页，并在页眉标出「第 2 / 4 张 · 列 33–64」，四角留十字对齐标记方便拼接。可以直接走浏览器打印（也能另存为 PDF），也可以单独导出 300dpi 的图纸 PNG 发给打印店。
- **自动保存**：每次改动自动写入 `localStorage`，刷新不丢；切走或关掉页面前会再补写一次，不会丢掉最后几笔。也可以手动「保存」并看到提示。
- **记住你的习惯**：工具、颜色、网格、对称、缩放都会跟着画布一起存下来，下次打开接着画。
- **完全离线可用**：字体随包发布，不请求任何外部 CDN，断网也能正常打开。
- **响应式**：桌面三栏、平板两栏、手机单栏都能用；手机上工具和清单自动重排。

## 开始使用

```bash
npm install
npm run dev      # 本地开发，默认 http://localhost:5173
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览构建产物
npm run lint     # oxlint
```

## 技术说明

- **栈**：React 19 + TypeScript（`strict`）+ Vite，无额外运行时依赖，图标全部为内联 SVG。
- **画布**：双 canvas 分层（底层豆子、上层悬停/高亮），绘制用 `requestAnimationFrame` 合批，64×64 拖动仍保持 60fps。
- **颜色**：`src/lib/colors.ts` 内置 39 色色卡与 sRGB → CIE Lab 转换，导入图片时按 Lab 距离匹配最接近的豆色。
- **存储**：单个 `localStorage` 键 `pindou.studio.v1`，内容是画布（`cols` / `rows` / `cells`）加一份 `prefs`（工具、色号、网格、对称、缩放）。写盘是 600ms 防抖，另外在 `pagehide` / 页面隐藏时立即补写一次。读回时逐项校验，坏数据直接退回默认，不会把界面带崩。隐私模式下写入失败会静默降级。
- **字体**：正文用系统字体（PingFang SC / 微软雅黑），标题的 ZCOOL KuaiLe 与色号用的 DM Mono 自托管在 `src/assets/fonts/`，只打包界面实际用到的字形，合计约 60KB，不发任何外部请求。
- **打印**：`src/lib/blueprint.ts` 全部按毫米排版，再按目标 DPI 一次性放大绘制（预览 104dpi、打印与导出 300dpi），所以屏幕预览、PNG、纸上三者完全一致。分页策略是「页数最少，且单格不小于 4.2mm」，64×64 会拆成 2×2 四张、每格 5.6mm。打印走隐藏的 `.print-root` + `@page A4 / margin 0`，其余界面在 `@media print` 里全部隐藏。

## 字体子集

标题字体是按当前文案裁过字形的子集。**改了界面文案（尤其新增汉字）之后**，跑一次：

```bash
python3 scripts/subset-fonts.py
```

脚本会重新扫描 `src/` 与 `index.html`，把用到的字符集打包进 woff2。忘了跑也不会崩，只是新加的字会回退成系统字体，标题风格会有点跳。

## 小提示

- 第一次打开会有一颗 29×29 的示例爱心；想从空白开始，点画布下方的「清空」即可（可撤销）。
- 换板尺寸会重建画布并裁掉超出部分，同样可以用 `Cmd/Ctrl + Z` 找回。
- 所有内容只在本机，换浏览器或清理站点数据后不会保留；重要图纸记得导出 PNG。
- 打印时把缩放设成「100% / 实际大小」、关掉页眉页脚，否则格子会被缩小，和实物对不上。想留档就在打印对话框里选「另存为 PDF」。
- 多张拼接时先按四角的十字标记对齐，再用胶带固定；图纸套进透明文件袋、用白板笔打勾，可以反复使用。
